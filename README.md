An end-to-end data pipeline for global market monitoring and AI-driven analysis  
(Scraping → AI Analysis → PostgreSQL → Power BI)

---

## 📌 Overview
This project automates the collection, processing, and analysis of global market data.  
It integrates web scraping, AI-generated insights, and database storage to support data-driven investment decisions.

---

## ⚙️ Architecture

TradingEconomics (Data Source)  
→ Python Scraper (Selenium)  
→ AI Analysis (Gemini)  
→ PostgreSQL Database  
→ Power BI Dashboard  

---

## 🚀 Features

- Automated web scraping of global market data  
- AI-powered market summary generation  
- Structured data storage in PostgreSQL  
- Workflow orchestration using Airflow  
- Dashboard visualization with Power BI  

---

## 🧰 Tech Stack

- **Python** (pandas, selenium)  
- **Airflow** (pipeline orchestration)  
- **PostgreSQL** (data storage)  
- **Power BI** (data visualization)  
- **Gemini API** (AI analysis)
