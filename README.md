An end-to-end data pipeline for global market monitoring and AI-driven analysis  
(Scraping → AI Analysis → PostgreSQL → Power BI)

---

## 📌 Overview
This project automates global market monitoring and transforms raw data into actionable insights.

It helps investment professionals:
- Track global market movements efficiently  
- Reduce manual data collection  
- Generate AI-driven summaries for faster decision making  
---

## ⚙️ Architecture

Data Source → Processing → Storage → Visualization

TradingEconomics  
→ Python (Selenium Scraper)  
→ Gemini AI (Summarization)  
→ PostgreSQL  
→ Power BI Dashboard  

---

## 🚀 Features

- Automated web scraping of global market data  
- AI-powered market summary generation  
- Structured data storage in PostgreSQL  
- Workflow orchestration using Airflow  
- Dashboard visualization with Power BI  

---

## 🧰 Tech Stack

- **Python** (pandas, selenium)  
- **Airflow** (pipeline orchestration)  
- **PostgreSQL** (data storage)  
- **Power BI** (data visualization)  
- **Gemini API** (AI analysis)

---
## 📊 Use Case

This pipeline is designed for:
- Investment analysts  
- Data analysts  
- Financial researchers  

It enables faster market insights, reduces manual workload, and supports data-driven decision making.
